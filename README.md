# Bidyoke

**Your Stage. Your Songs.**

Bidyoke is an Android videoke app inspired by traditional karaoke machines, with a modern interface for Android phones, tablets, and TV.

## Product experience

1. Find a song in the songbook or enter its assigned number.
2. Add the request to the queue.
3. Sing when the song reaches the top of the queue.
4. Watch the karaoke video with synchronized lyrics displayed underneath.

## Phase 1 — Android shell

- Kotlin, Jetpack Compose, and Material 3
- Dark charcoal and violet theme
- Home, Songbook, Karaoke, and Settings destinations
- Numeric song request keypad
- Queue preview and sample songbook entries
- Adaptive navigation rail and bottom navigation
- Room and DataStore dependencies established

Song entries and karaoke lyrics are UI placeholders. Playback engines, real song import, synchronized lyric rendering, microphone mixing, and persistent database behavior are later milestones.

## Build with Android Studio

1. Open this repository as a project in Android Studio.
2. Use JDK 17.
3. Install Android SDK Platform 36 if prompted.
4. Sync Gradle and run the app on an Android device or emulator.

## Planned media support

MIDI, KAR, MP3, and LRC, with local video backgrounds and synchronized lyrics. Use song and video files that you own or are licensed to use.

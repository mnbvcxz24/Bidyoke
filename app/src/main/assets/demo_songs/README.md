# Bidyoke demo KAR pack

These four short demo songs are original compositions written for Bidyoke testing:
- 00125 — Midnight Drive (English)
- 00126 — Bituing Gabay (Filipino)
- 00127 — Summer Lights (English)
- 00128 — Awit ng Umaga (Filipino)

Each .kar file is a Standard MIDI File with a melody, simple accompaniment, tempo metadata, and timestamped lyric meta-events (MIDI FF 05). The compositions and lyrics are original and may be used, modified, and redistributed with the Bidyoke project.

These are short technical test tracks, not commercial-quality arrangements. The current app copies them into its private files/demo_songs directory on first launch. MIDI/KAR playback is not yet connected to the player UI.
